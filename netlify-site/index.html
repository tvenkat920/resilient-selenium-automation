Architecture

Core Components

Four purpose-built classes form the backbone of the framework, each with a focused responsibility that keeps test code clean and maintainable.

🔍

ResilientElementFinder

The heart of the framework. Aggregates confidence scores across all 7 locator signals, ranks candidate elements, enforces an ambiguity threshold, and retries automatically on StaleElementReferenceException.

🏆

CandidateScorer

Stateless scoring engine that evaluates each DOM candidate against user-specified hints — label proximity, ARIA attributes, placeholder text, semantic roles — and returns a normalized confidence score between 0.0 and 1.0.

📋

FormPage

Page Object encapsulating every interaction with the target form. Exposes strongly-typed methods (EnterFirstName, SelectGender, SelectState) that delegate to ResilientElementFinder internally.

⚙️

DriverFactory

Manages WebDriver lifecycle with per-test [SetUp]/[TearDown] hooks. Supports Chrome (headless or headed), captures screenshots on assertion failure, and disposes cleanly after every test.

Multi-Signal Strategy

7 Locator Signals

Instead of a single brittle selector, the framework combines up to seven independent signals to identify the intended element with high confidence, even when markup changes.

1
Label Text Matches <label for> associations and implicit label wrapping using exact and fuzzy text comparison.
2
Nearby Text Scores siblings and parent text nodes within a configurable DOM-distance radius around each candidate.
3
Accessible Name Reads aria-label, aria-labelledby, and title attributes per ARIA specification.
4
Placeholder Checks the placeholder attribute for text inputs — a reliable, stable hint in modern forms.
5
Input Type / Semantic HTML Uses type attribute and semantic elements (select, textarea) to scope candidates.
6
DOM Relationships Leverages parent-child and sibling relationships to disambiguate elements with identical labels in repeated form blocks.
7
Option Text / Group Context For <select> and radio groups, matches <option> text and <optgroup> labels.

Resilience Features

Built for the Real World

Flaky tests are a tax on engineering velocity. These four mechanisms work together to keep the suite green even as the DOM changes beneath it.

🎯

Confidence Threshold

Every element interaction is gated by a minimum confidence score. If no candidate reaches the threshold, the test fails fast with a descriptive message instead of silently operating on the wrong element.

🔄

Stale Element Retry

StaleElementReferenceException is caught transparently. The finder re-runs the full multi-signal search up to 3 times with exponential backoff before surfacing the error to the test.

📸

Screenshot on Failure

On any assertion failure or unhandled exception, the framework automatically captures and saves a timestamped PNG screenshot, making root-cause analysis fast and painless.

⚠️

Ambiguity Detection

When two or more candidates achieve similar confidence scores, the framework raises an AmbiguousMatchException rather than guessing — a critical guard against silent wrong-element interactions.
